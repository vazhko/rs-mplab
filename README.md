# Random PIC10F200 GP2 pulse generator

Репозиторій містить один файл `main.c`, що працює на `PIC10F200` і керує GP2 так,
щоб він генерував одиничні чи нульові рівні з випадковою тривалістю (1–3 с для одиниці, решта часу до
4-секундного циклу — нуля). Логіка використовує простий LFSR і забезпечує, щоб обидві фази тривали не менше 1 секунди.

## Складання
- Відкрийте проект у MPLAB X з налаштованим компілятором XC8 2.50.
- Цільовий пристрій: `PIC10F200`.
- Конфігураційні біти: `OSC = IntRC`, `WDTE = ON`, `MCLRE = OFF`, `CP = OFF`.
- Команда `make` у цьому Unix-середовищі не працює, тому збірку та прошивку слід виконувати у Windows з встановленим MPLAB X.

## Тестування
- `make` — не проходить в оболонці Bash через Windows-специфічні шляхи/утиліти (`xc8-cc.exe`), тож тестування вимагає MPLAB X під Windows.

## Сторожовий таймер
- У коді ввімкнено WDTE, тому сторожовий таймер потребує періодичного `CLRWDT()` під час затримок, аби мікроконтролер не перезапускався під час 4-секундних циклів.

## Наступні кроки (за потреби)
1. Зібрати та прошити на реальному `PIC10F200`.
2. Перевірити, що GP2 змінює рівень з довільними тривалостями у межах 4-секундного циклу.
