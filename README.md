# Random PIC10F200 GP2 pulse generator

Репозиторій містить один файл `main.c`, що працює на `PIC10F200` і керує GP2 так,
щоб у вікні 2 с випадково у часі вмикати пін на 1 с, а між циклами тримати паузу не менше 0.2 с.
Рандомний вибір зсуву базується на значенні `TMR0`, без використання RAM.

## Складання
- Відкрийте проект у MPLAB X з налаштованим компілятором XC8 2.50.
- Цільовий пристрій: `PIC10F200`.
- Конфігураційні біти: `OSC = IntRC`, `WDTE = OFF`, `MCLRE = OFF`, `CP = OFF`.
- Команда `make` у цьому Unix-середовищі не працює, тому збірку та прошивку слід виконувати у Windows з встановленим MPLAB X.

## Тестування
- `make` — не проходить в оболонці Bash через Windows-специфічні шляхи/утиліти (`xc8-cc.exe`), тож тестування вимагає MPLAB X під Windows.

## Наступні кроки (за потреби)
1. Зібрати та прошити на реальному `PIC10F200`.
2. Перевірити, що GP2 вмикається на 1 с у межах 2-секундного вікна і має паузу не менше 0.2 с між циклами.
